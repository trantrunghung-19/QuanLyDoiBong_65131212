# ⚽ QuanLyDoiBong_65131212

Ứng dụng **Quản Lý Đội Bóng** là app Android được xây dựng bằng **Java + XML**, sử dụng **Firebase Authentication** để đăng ký/đăng nhập và **Cloud Firestore** để lưu trữ dữ liệu đội bóng, cầu thủ và huấn luyện viên.

---

## 👨‍💻 Thông tin dự án

| Nội dung | Thông tin |
|---|---|
| Tên dự án | Quản Lý Đội Bóng |
| Nền tảng | Android |
| Ngôn ngữ | Java |
| Giao diện | XML |
| Cơ sở dữ liệu | Cloud Firestore |
| Xác thực | Firebase Authentication |

---

## 🚀 Chức năng chính

- Đăng ký tài khoản.
- Đăng nhập tài khoản.
- Cập nhật mật khẩu.
- Xem thống kê tổng số đội bóng và tổng số cầu thủ.
- Xem danh sách đội bóng.
- Thêm đội bóng mới.
- Xem chi tiết đội bóng.
- Thêm cầu thủ vào đội bóng.
- Xem chi tiết cầu thủ.
- Sửa và xóa cầu thủ.
- Xem và cập nhật thông tin huấn luyện viên.
- Đăng xuất tài khoản.

# 🔥 Firebase

Ứng dụng sử dụng Firebase với các chức năng:

- **Firebase Authentication**: đăng ký, đăng nhập và đăng xuất tài khoản.
- **Cloud Firestore**: lưu trữ thông tin đội bóng, cầu thủ và huấn luyện viên.

# 📌 Kết luận

Ứng dụng **Quản Lý Đội Bóng** đã hoàn thành các chức năng cơ bản của một hệ thống quản lý đội bóng trên thiết bị di động. App có giao diện đơn giản, dễ sử dụng, dữ liệu được lưu trữ trực tuyến bằng Firebase và phù hợp cho bài tập lớn môn lập trình Android.
